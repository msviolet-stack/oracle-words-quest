# Oracle Word Quest

This folder contains the complete, colourful bilingual MCQ game. It runs directly in a browser and does not collect student information.

## Publish on GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and the complete `images` folder.
3. Open the repository's **Settings**, then select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the **main** branch and **/(root)** folder, then click **Save**.

GitHub will display the game's public link after publishing finishes.
